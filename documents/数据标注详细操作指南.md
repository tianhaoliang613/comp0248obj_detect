## 第二步：手动选择需要标注的帧（100 帧）

### 要求：

- **关键帧要求**：
  - 两帧之间至少间隔 1 秒（即至少间隔 3 帧，因为帧率是 3fps）

### 操作步骤：
1. 打开 `dataset/labelling/images/` 文件夹
2. 浏览所有图片，为每个 clip 选择 2 帧
3. **删除不需要标注的帧**（保留 100 帧，删除其余 650 帧）
4. 建议记录选择的帧号，例如：
   - `G01_call_clip01_rgb_frame_005.png` 和 `G01_call_clip01_rgb_frame_012.png`
   - `G01_call_clip02_rgb_frame_003.png` 和 `G01_call_clip02_rgb_frame_010.png`
   - ... 以此类推

确认 `dataset/labelling/images/` 文件夹中只剩下 100 个 PNG 文件

## 第五步：安装并配置 Label Studio

   ```cmd

   set LABEL_STUDIO_LOCAL_FILES_DOCUMENT_ROOT=D:\UCL_ROBOTICS\comp2048_objectiondetect\dataset
   ```

   **方法 B：使用 PowerShell**：
   ```powershell
   $env:LABEL_STUDIO_LOCAL_FILES_SERVING_ENABLED="true"
   $env:LABEL_STUDIO_LOCAL_FILES_DOCUMENT_ROOT="D:\UCL_ROBOTICS\comp2048_objectiondetect\dataset"
   ```

2. **验证环境变量**：

   **CMD 中验证**：
   ```cmd
   echo %LABEL_STUDIO_LOCAL_FILES_SERVING_ENABLED%
   echo %LABEL_STUDIO_LOCAL_FILES_DOCUMENT_ROOT%
   ```

   **PowerShell 中验证**：
   ```powershell
   echo $env:LABEL_STUDIO_LOCAL_FILES_SERVING_ENABLED
   echo $env:LABEL_STUDIO_LOCAL_FILES_DOCUMENT_ROOT
   ```
应该分别显示 `true` 和您的 dataset 路径

3. **启动 Label Studio**：
```bash
label-studio
```

4. **浏览器会自动打开** Label Studio 界面（通常是 http://localhost:8080）

---

## 第六步：在 Label Studio 中创建项目并导入数据

### 操作步骤：

1. **创建新项目**：
   - 点击 "Create Project"
   - 输入项目名称（例如："Hand Gesture Annotation"）
   - 点击 "Create"

2. **配置标注界面（Code 标签页）**：
   - 点击 "Code" 标签
   - 粘贴以下 XML 代码：
```xml
<View>
  <Image name="image" value="$image" zoom="true" zoomControl="true" rotateControl="false"/>
  <BrushLabels name="tag" toName="image">
    <Label value="hand" background="red"/>
  </BrushLabels>
</View>
```
   - 点击 "Save"

3. **跳过 Data Import 标签页**（先不要导入图片）

4. **配置本地文件存储**：
   - 点击左侧 "Settings" → "Cloud Storage"
   - 点击 "Add Source Storage"
   - 选择 "Local Files"
   - 名称：任意（例如："Local Dataset"）
   - 绝对路径：`D:\UCL_ROBOTICS\comp2048_objectiondetect\dataset\labelling`
   - 点击 "Add Storage"
   - **重要**：不要点击 "Sync Storage"（否则会重复导入图片）

5. **返回项目主页**：
   - 点击页面顶部的项目名称

6. **导入标注文件**：
   - 点击 "Import" 按钮
   - 选择 `dataset/labelling/labels.json` 文件
   - 点击 "Import"

### 预期结果：
- 您应该看到 100 个任务（tasks）
- 每个任务都有一张 RGB 图片和 SAM3 生成的预标注掩码（红色区域表示手部）

---

## 第七步：在 Label Studio 中修正掩码

### 操作步骤：

1. **打开第一个任务**：
   - 点击任意一个任务开始标注

2. **使用画笔工具修正掩码**：
   - **添加手部区域**：选择 "hand" 标签，用画笔在未标注的手部区域涂抹
   - **删除错误区域**：按住 Alt 键（或使用橡皮擦工具）擦除背景区域中被误标为手部的部分
   - **确保掩码准确**：
     - 手部区域应该是白色（或红色高亮）
     - 背景区域应该是黑色
     - 手部完整，没有被裁剪

3. **保存并提交**：
   - 完成修正后，点击 "Submit" 按钮
   - 继续下一个任务

4. **批量标记完成**（可选）：
   - 如果所有任务都已检查/修正完成
   - 点击页面上的 "Label All Tasks" 按钮
   - 这会将所有任务标记为完成状态

### 重要提示：
- 即使 SAM3 生成的掩码已经很准确，也需要点击 "Submit" 提交每个任务
- 只有标记为 "Completed" 的任务才会在导出时包含

---

   - 下载导出的 JSON 文件

2. **放置导出文件**：
   - 将下载的 JSON 文件移动到项目根目录（`D:\UCL_ROBOTICS\comp2048_objectiondetect\`）
   - 重命名为 `annotations.json`

3. **运行转换脚本**：
   - 在命令行中运行：
```bash
python annotation_scripts/annotation_scripts/process_LS_output.py
```

### 预期结果：
- 脚本会读取 `annotations.json`
- 将每个掩码转换为 PNG 图片
- 自动放置到对应的 `annotation/` 文件夹中
- 例如：`G01_call/clip01/annotation/frame_005.png`

### 验证：
检查各个 clip 的 `annotation/` 文件夹，应该看到：
- 每个 clip 有 2 个掩码 PNG 文件
- 总共 100 个掩码文件（50 clips × 2 frames）

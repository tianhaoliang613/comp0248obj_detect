# CNN 手写数字识别学习笔记

## 1. 核心概念：CNN 的“三板斧”

可以将 CNN 想象成一个流水线，每个环节各司其职：

1.  **卷积层 (Convolution, Conv)**：**“找特征”**
    *   **作用**：使用一组可学习的滤波器（卷积核）扫描图像，提取如边缘、纹理、形状等特征。
    *   **维度变化**：通道数 (Channels) 会变（比如 1 -> 32），长宽通常不变（如果用了 Padding）。
    *   **本质**：最初是随机初始化的矩阵，通过训练自动分化成不同的特征探测器。

2.  **池化层 (Pooling, MaxPool)**：**“做压缩”**
    *   **作用**：下采样，保留最显著的特征（最大值），丢弃多余的空间信息。
    *   **好处**：减少计算量，防止过拟合，增加平移不变性（物体稍微移位也能认出来）。
    *   **维度变化**：通道数不变，长宽减半（如 28x28 -> 14x14）。

3.  **全连接层 (Fully Connected, FC)**：**“下结论”**
    *   **作用**：汇总前面提取的所有特征，进行逻辑判断，输出分类概率。
    *   **维度变化**：将多维特征图展平 (Flatten) 为一维向量，最后映射到类别数（如 10 类）。

## 2. 关键代码解析

### 模型架构 (`model.py`)
一个经典的 **Conv -> Pool -> Conv -> Pool -> FC** 结构：

```python
# 输入: [Batch, 1, 28, 28]

# 第一层：提取低级特征
self.conv1 = nn.Conv2d(1, 32, 3, padding=1)  # -> [32, 28, 28]
# MaxPool(2)                                 # -> [32, 14, 14]

# 第二层：提取高级特征
self.conv2 = nn.Conv2d(32, 64, 3, padding=1) # -> [64, 14, 14]
# MaxPool(2)                                 # -> [64, 7, 7]

# 展平 (Flatten)
# 64个通道 * 7(高) * 7(宽) = 3136
x = torch.flatten(x, 1)                      # -> [Batch, 3136]

# 全连接层：分类
self.fc1 = nn.Linear(3136, 128)              # -> [128]
self.dropout = nn.Dropout(0.5)               # 随机丢弃50%，防止死记硬背
self.fc2 = nn.Linear(128, 10)                # -> [10] (对应0-9的打分)
```

### 训练流程 (`train.py`)
*   **Batch Dimension**: 训练时是一批批进行的（如 64 张），所以数据形状是 `[64, 1, 28, 28]`。
*   **Loss 计算**: `LogSoftmax` (输出层) + `NLLLoss` (损失函数) = **交叉熵损失 (Cross Entropy)**。
*   **训练步骤**:
    1.  `optimizer.zero_grad()`: 梯度清零（别忘了！）。
    2.  `output = model(data)`: 前向传播。
    3.  `loss = criterion(output, target)`: 算误差。
    4.  `loss.backward()`: 反向传播求梯度。
    5.  `optimizer.step()`: 更新参数。

## 3. 常见疑问解答 (Q&A)

*   **Q: 为什么卷积核数量从 32 变成 64？**
    *   A: 这是一种设计模式。随着网络变深，图像尺寸变小（被池化了），我们通常增加通道数来存储更丰富、更抽象的特征组合。

*   **Q: 为什么最后特征图大小是 7x7？**
    *   A: 这是一个平衡点。
        *   **太大 (14x14)**：全连接层参数会爆炸，计算太慢且易过拟合。
        *   **太小 (1x1)**：空间信息丢失太多，分不清复杂物体。
        *   **7x7**：保留了足够的空间布局信息，计算量又在可控范围内。

*   **Q: 为什么 Conv2 后面还要池化？**
    *   A: MNIST 图片小 (28x28)，池化两次刚好到 7x7。如果是大图 (224x224)，通常需要池化 5 次才能压到 7x7。核心目标是把图变小，方便全连接层处理。

*   **Q: `dropout(x)` 是什么？**
    *   A: 训练时随机让一半神经元“罢工”。这强迫模型利用所有线索，而不是依赖某几个特定的神经元，从而提高模型的泛化能力（防作弊）。

*   **Q: 卷积核是怎么初始化的？**
    *   A: 既然叫“人工”智能，当然是……自动生成的！PyTorch 默认使用 Kaiming 或 Xavier 初始化算法生成随机数。通过训练，它们会自动进化成有用的特征探测器。

## 4. 经典 CNN 架构通式

图像分类任务的模型设计通常遵循这个公式：

$$
\text{Input} \rightarrow [\underbrace{\text{Conv} + \text{Pool}}_{\text{特征提取 (排列组合)}}] \times N \rightarrow \text{Feature Map (e.g. } 7 \times 7) \rightarrow [\underbrace{\text{Flatten} + \text{FC}}_{\text{分类器}}] \rightarrow \text{Output}
$$

*   **前半部分 (积木)**：负责把图片从“像素矩阵”变成“特征浓缩块”。
*   **后半部分 (套路)**：负责根据浓缩块里的特征进行分类。
